# 🎓 Smart Campus - Digital Society & Event Management Hub

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Language: JS](https://img.shields.io/badge/Language-JavaScript-F7DF1E.svg)](https://javascript.com)
[![Status: Production Ready](https://img.shields.io/badge/Status-Production--Ready-brightgreen.svg)]()

**Smart Campus** is a premium, all-in-one digital ecosystem designed for modern universities. It streamlines student engagement through society management, event tracking, and personalized achievement systems. Built with a sleek Gen-Z aesthetic, it offers a high-performance user experience with a live MySQL backend.

---

## 🌟 Key Features

- 🔐 **Unified Authentication** — Secure login and registration with personalized student profiles.
- 📅 **Dynamic Event Hub** — Browse, filter, and register for campus events with real-time seat availability.
- 🏛️ **Society Management** — Join campus societies, participate in activities, and manage memberships.
- 🏆 **Achievement System** — Earn unique digital badges and track progress through a dynamic activity log.
- 📊 **Feedback & Ratings** — Interactive review system with visual data representation (bar charts/star ratings).
- 🎨 **Premium UI/UX** — Fully responsive dark-themed design with smooth animations and interactive components.
- ⚡ **Hybrid Logic** — Utilizes React components for complex search logic and vanilla JS for optimized performance.

## 🚀 Getting Started

### Prerequisites
- **XAMPP / WAMP / MAMP** (For local server environment)
- **Git** (For version control)

### Installation

1. **Clone the Repository**
   ```bash
   git clone git@github.com:KhizarDoingProgramming/smart-campus.git
   cd smart-campus
   ```

2. **Database Configuration**
   - Open **phpMyAdmin**.
   - Create a new database named `smart_campus`.
   - Import the `database.sql` file provided in the root directory.

3. **Deploy Locally**
   - Move the `smart-campus` folder to your server's root directory (e.g., `C:/xampp/htdocs/` or `/var/www/html/`).
   - Open your browser and navigate to `http://localhost/smart-campus/index.html`.
